# SCM---Monolith-Towards-Microservices
SCM: Monolith to Microservices. High-performance core built with Java 21 &amp; Spring Boot 4. Features Project Loom (Virtual Threads) for high-concurrency warehouse transactions, jOOQ for type-safe persistence, and Pessimistic Locking for data integrity. Containerized with Docker &amp; ready for modular scaling.
